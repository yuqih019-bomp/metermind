# MeterMind support

For product questions, bug reports, or feature requests, open a GitHub issue in this repository.

Please do not include billing exports, account numbers, API keys, access tokens, or other private information in public issues.

When reporting a problem, include:

- the browser and version;
- whether the input was CSV or JSON;
- the visible error message; and
- a small anonymized example, if one is necessary to reproduce the issue.
